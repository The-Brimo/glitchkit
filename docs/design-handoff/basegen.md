# basegen — A Beginner's Guide

`basegen` makes **procedural base images** — pictures generated by math and rules rather than drawn or photographed. You pick a generator (an algorithm), it produces a black-and-white *brightness field*, and a *palette* colors it in. The result is a PNG you can use on its own or feed into the glitch tools (`pixelsort.py`, `databend.py`) sitting next to it.

No two runs need to look alike, and every image is reproducible: same settings always give the same picture.

---

## Before you start

Everything lives in one folder (the `glitchkit` folder). You only need to do the full setup once — if you already ran `./setup.sh`, skip to the next section.

First-time setup:

```bash
cd ~/path/to/glitchkit     # wherever you saved the kit
./setup.sh                 # installs the libraries into a local environment
```

**Every time you open a new Terminal window**, you must "activate" the environment before running anything. This is the single most common thing new users forget:

```bash
cd ~/path/to/glitchkit
source .venv/bin/activate
```

When it works, your prompt will start with `(.venv)`. That's how you know you're ready. If you skip this step you'll get an error like `ModuleNotFoundError: No module named 'numpy'` — that just means the environment isn't active. Run the `source` line and try again.

## Your first image

Type this:

```bash
python3 basegen.py --gen noise --seed 1 --out first.png
```

Open `first.png`. You just generated a flowing, cloud-like image. Now change one number — the seed — and run it again:

```bash
python3 basegen.py --gen noise --seed 2 --out second.png
```

Completely different image, same style. **The seed is your "which random picture" dial.** That's the whole loop: change a setting, run, look. Let's go through the settings worth knowing.

---

## How it works (the one idea)

Every run follows the same four steps:

1. **Generator** — an algorithm fills the canvas with a grayscale pattern.
2. **Field** — that grayscale result, where white = bright, black = dark.
3. **Palette** — colors are mapped onto the brightness (e.g. dark → teal, bright → orange).
4. **PNG** — the colored result is saved.

So "the color follows the brightness." If you understand that, you understand the tool. Generators decide the *shape*; palettes decide the *mood*.

To see everything available at any time:

```bash
python3 basegen.py --list
```

## The controls you'll use most

These work with any generator:

| Setting | What it does |
| --- | --- |
| `--seed N` | Which random version you get. Same seed = same image, every time. |
| `--size WxH` | Output dimensions, e.g. `--size 1600x900`. Or `--size 1000` for square. |
| `--palette` | The color scheme (see list below). |
| `--gamma N` | Shifts where the bright areas fall. Above 1 darkens the middle tones; below 1 lifts them. Great for tuning how much "glow" there is. |
| `--invert` | Flips dark and light. |
| `--out NAME` | The filename to save. |

Palettes available: `ember` (teal-to-orange, fiery), `ice` (deep blue to white), `magma` (purple-to-yellow), `acid` (green-to-lime), and `mono` (plain grayscale).

Example combining several:

```bash
python3 basegen.py --gen noise --seed 5 --size 1600x900 --palette ice --gamma 1.3 --out cool.png
```

## The generators

### `noise` — soft, flowing, organic

Makes clouds, smoke, marble, and gradient-like fields. Fast (about a second).

Its own knobs are passed with `-p name=value`:

- `-p octaves=6` — more octaves = more fine detail (try 3 to 8).
- `-p freq=4` — bigger number = smaller, busier features.
- `-p warp=1.2` — bends and swirls the pattern (0 = off; try 0.5 to 2).

```bash
python3 basegen.py --gen noise --seed 7 --palette ember --out clouds.png
python3 basegen.py --gen noise --seed 7 --palette ember -p warp=1.5 -p octaves=6 --out swirled.png
```

### `reaction` — patterns that look alive

This runs a tiny chemistry simulation (the Gray-Scott model) that grows coral, mazes, spots, and fingerprint patterns. Because it's a real simulation, **it's slow — expect around 10–15 seconds per image.** That's normal.

Knobs:

- `-p preset=NAME` — the pattern type. Try: `coral`, `maze`, `spots`, `mitosis`, `fingerprint`, `flower`.
- `-p steps=5000` — how long to simulate. More steps = more developed pattern (and more time).
- `-p sim=200` — internal detail level. Higher = finer but slower.

```bash
python3 basegen.py --gen reaction --seed 3 -p preset=coral --palette ice --out coral.png
python3 basegen.py --gen reaction --seed 5 -p preset=maze --palette ember --out maze.png
```

If you want it faster while experimenting, lower the numbers (`-p steps=2500 -p sim=160`), then turn them back up once you like a result.

## Turning a base into glitch art

This is where it gets fun. The PNGs `basegen` makes are ready to feed into the glitch tools in the same folder.

**Pixel sorting** works directly on the PNG. This is what made the dripping, streaked look:

```bash
python3 basegen.py --gen noise --seed 7 --palette ember --out base.png
python3 pixelsort.py base.png sorted.png --direction vertical --low 25 --high 140
```

**Databending** needs a JPEG (not PNG), so save or convert your base to `.jpg`first, then bend it:

```bash
sips -s format jpeg base.png --out base.jpg     # convert (built into macOS)
python3 databend.py base.jpg bent.jpg --mode random --amount 250 --seed 7
```

Mix and match freely: generate a coral pattern, pixel-sort it; generate warped noise, databend it. The generator gives you the raw material; the glitch tools wreck it beautifully.

## A few things to try

- Run the same seed through every palette to see how mood changes shape.

- Generate one noise image, then sort it vertically *and* horizontally into two versions.

- Make a batch and keep the best:

  ```bash
  for s in $(seq 1 10); do python3 basegen.py --gen noise --seed $s --out noise_$s.png; done
  ```

- Crank `--gamma` up to 2.0 on an ember noise image for a dark, glowing-core look.

- Try `reaction` with `preset=mitosis` and the `magma` palette.

## Troubleshooting

- `ModuleNotFoundError` → you didn't activate the environment. Run `source .venv/bin/activate` (you should see `(.venv)` in your prompt).
- `unknown generator` → run `python3 basegen.py --list` to see the exact names.
- **Reaction-diffusion takes forever** → that's expected; lower `-p steps=` and `-p sim=` while experimenting.
- **The image looks flat or washed out** → try a different `--seed`, adjust `--gamma`, or pick a palette with more contrast like `ember` or `magma`.
- **Databend complains about the file** → it only accepts JPEGs. Convert your PNG first with the `sips` command shown above.
